# 匿名案例：一个桌面 CAD/CAE 套件的自动化 skill

这不是教程，是把前面的原则放回真实项目里，看看哪些真的省时间、哪些真的返工。

## 背景

- 软件：某工业设计 CAD/CAE 套件，Windows 桌面，模块化（建模、分区、计算、出图）。
- 表面限制：没有公开 API 文档；启动要走厂商包装脚本；浮动许可；项目是 SQLite 数据库；界面是旧版 Qt。
- 目标：把“改模板 → 生成几何 → 套图框 → 导出图纸 → 校验结果 → 打包交付”做成一条可重复的命令。

## 阶段对照

| 阶段 | 实际做的事 | 结果 |
|---|---|---|
| 0 定边界 | 明确交付物：A0 图 + 数据表 + 数值校核 + ZIP；验收用数值容差和字节比对 | 后续没有跑偏 |
| 1 侦察 | 读包装脚本拿到许可/配置/日志路径；发现项目是 SQLite；CHM 和示例工程里有命令名 | 少走了大量 UI 弯路 |
| 2 选层 | 直读 DB 拿结果；内嵌脚本引擎做建模；GUI 只做必须点的那几步 | 核心计算完全不靠界面 |
| 3 闭环 | 先做“读库 → 算 → 导出 CSV”一条链；再做 GUI 触发 | 早期就能验证数据正确 |
| 4 工程化 | 只读连接、副本、dry-run、wait_until、残留进程清理、selftest、黄金 md5 | 长任务可无人值守 |
| 5 封装 | SKILL.md 决策树 + 分层 references + 单入口 CLI + evals | 新会话能直接接手 |

## 最有效的五个发现（按投入产出比）

1. **启动包装脚本**：一次读明白，解释了大部分“打不开/许可失败/日志在哪”的问题。
2. **SQLite 直读**：软件把计算结果写进项目库；直读比点界面快、稳，且能与界面结果对上。
   - 实测：独立积分与软件结果的关键数值差 **-0.024%**，其余指标都在 0.1% 内。
3. **内嵌脚本引擎**：可以无人值守建模/出图；关键是先录制一段人工操作，再照着录制结果写，不要猜 API。
4. **日志**：界面只弹“操作失败”，真实原因在日志的 `DLGMESSAGE` 字段里。
5. **UIA 控件树**：标准控件（停靠面板、标签、表格行）能按名称定位；自绘控件不行。

## 返工最多的八个坑

| 坑 | 现象 | 根因 | 修法 |
|---|---|---|---|
| 直填 Qt 输入框 | 填完被清空，OK 变灰 | 控件不支持 ValuePattern/直接设值 | 点 “...” 走系统文件对话框，或用剪贴板 |
| 逐字键入路径 | 文件名变成乱码 | 中文输入法介入 | 剪贴板 + Ctrl+V |
| `Ctrl+S` 保存 | 没反应，或弹空文件名对话框 | 快捷键未绑定；对话框文件名为空 | 显式填唯一文件名；避免覆盖确认 |
| 拖放 | 拖了没反应 | 整行矩形中心是空白 | 落在行文字起点（如 left+18） |
| 点击错窗口 | 点了别的应用 | 前台被开始菜单/其他窗口抢占 | 每次点击前校验前台窗口 |
| 坐标漂移 | 换机器/换缩放后全偏 | 150% DPI；面板布局变化 | 按标签/结构定位；坐标校准并告警 |
| 长计算超时 | 固定 sleep 不够或白等 | 计算 3–20 分钟，进度 100% 不关窗 | 轮询 DB 行数/文件大小/日志关键字 |
| 文件锁/残留 | 第二次启动报 database locked | 上次崩溃没退干净；单实例 | finally 清理；启动前检测并结束残留 |

## 一个“不要走”的路径

目标是让软件把一个开放曲面壳识别成封闭实体。试过：

- 开放壳、闭合 IGES、多个 patch 组合；
- 六面边界（六个坐标面）反复调；
- 形状修复（不同容差）。

结论：软件内部对 patch 重叠/重算有额外约束，界面上“看起来封闭”不等于能建实体。继续投入没有产出。

**转向**：改用“导入闭合实体（BREP/STEP）作为空间”的路径，一次成功。之后所有流程都走实体，不再碰六面边界。

教训：**一条路连续失败三次，就换入口，而不是更用力地调参数。** 把“不要走的路”写进文档，比写十页成功经验更省后来者的时间。

## 有效的工作方式

- **小步**：每次只改一个动作，点完立即用数据/截图确认。
- **先只读**：项目库一律只读；改写先复制；原库时间戳/校验和留底。
- **GUI 只做扳机**：点“Calculate”后，等数据库结果，而不是等界面变绿。
- **黄金输出**：同一模型重开再导出，DXF 字节一致（md5 相同）；交付包写 SHA256。
- **端到端一条命令**：把十几个 GUI 步骤收成 `deliver lines`，实测 305 秒、退出码 0。
- **selftest**：环境、依赖、脚本编译、模板、可选启停，逐项 OK/WARN/FAIL；新机器先跑它。

## 封装后的效果

- 新会话先读 SKILL.md 的决策树，就能找到“读库/建模/出图/排障”对应命令。
- 长流程（如交付包）有独立 reference，主文件不膨胀。
- 已知限制单独列出，避免把“未验证”当成“已支持”。
- 公开发布前做隐私扫描：本机路径、用户名、许可证、客户/项目数据全部清除；内部实现留在私有版。

## 案例特有 vs 通用模式

| 案例里的具体做法 | 通用模式 |
|---|---|
| 读厂商 `.bat` 拿许可/配置 | 先读启动包装脚本 |
| SQLite `DSG_*` 表 | 直读项目数据库做验收 |
| 内嵌 QtScript/命令机 | 优先用内嵌脚本/宏，录制优先 |
| UIA + win32 + QPopup 键盘导航 | 定位级联 + 键盘兜底 |
| 150% DPI、1920×1080 实测坐标 | DPI/分辨率校准清单 |
| 中文路径不能进 Offset table | ASCII 工作目录 + 最后复制 |
| 六限界失败 | 三次失败换入口，记录“不要走” |
| 公开版/私有版分仓 | 脱敏与发布审计 |

本文件只保留可复用的模式，不含具体软件名、路径、许可和项目数据。
